常见问题

先看这里，能省下在频道里问一遍的时间。

要花钱吗？要注册吗？会收集我的数据吗？

都不要。免费、无账号、无广告、无内购；存档只写在你自己的浏览器或手机里，游戏本身不联网（除非你自己配置了更新地址）。

需要联网吗？

不需要。网页版首次打开后可以「添加到主屏幕」离线玩；安卓版装完就能断网玩。 只有 v2.7 的更新检查需要网络，而且默认是关闭的。

手机上怎么装 APK？

点「下载 APK」→ 打开文件 → 系统会提示「未知来源应用」，允许安装即可。 这个包用的是调试签名（个人项目，没买代码签名证书），所以会有提示，但功能完全正常。

AI 对战是什么？AI 会作弊吗？

AI 那一局是引擎里真的第二局：同样的知识收益曲线、同样的疲劳与心情、同样的遗忘规则， 它每周的选择由内置打法决定（佛系 / 均衡 / 卷王 / 竞赛四种）。所以它的分数是打出来的， 不是凭空生成的，也不会偷偷改你的数值——同一个种子跑两遍，结果完全一样。 强度分四档：陪跑型、均衡型、卷王型、竞赛型（后者可能根本不参加高考，直接保送）。

排行榜怎么上榜？昵称会被别人看到吗？

会——昵称就是榜上显示的名字，所以别填真名。第一次进游戏会问你怎么称呼， 这个昵称只存在你自己的设备里，随时能在「🏆 排行榜」面板里改。打完一局在结局页点「🏆 上榜」就提交了。 提交的内容只有：昵称、结局、高考总分、年级名次、难度、单人还是 AI 对战、图鉴与成就收集数， 以及随机种子和构筑摘要（用来让人复核同一局）——没有设备信息、没有账号、没有位置。 不想上榜，就永远别点那个按钮。加载不出来（比如你所在网络连不上榜单服务器）也不影响玩， 游戏会自动退回本机成绩榜。

游戏里的学校和分数线是真的吗？

全部为虚构娱乐内容，与任何真实学校、机构、个人无关。 录取档次参考了常见口径，但数值是为游戏性设定的。

一局要玩多久？

三年 36 周、每周两段，一路点完大约 10～20 分钟；可以随时存档、导出角色卡。 嫌长可以在开局把每学期周数调短，或者用自由模式自己决定什么时候高考。

为什么我熬夜刷题反而考得更差？

这是故意的：疲劳超过 45 之后学习效率会往下掉，知识收益还会边际递减。 心情和疲劳比「多刷一套卷子」更影响分数——先睡一觉再学经常更划算。

可以调难度 / 作弊吗？

自定义难度有 8 根滑杆（成长、遗忘、开局底子、零花钱、事件频率、考试波动、属性点、偏科）， 开局还有 5 个缺陷可以换属性点。想轻松玩就调，没人管你。

内容会继续更新吗？

会。新事件、新道具、平衡调整可以通过热更新内容包推送，不用重新装 APK； 只有引擎规则变化才需要出新包。更新消息会发在下面的腾讯频道里。

打完一局之后，在游戏里点「🏆 上榜」就提交到这儿。难度不同分数本来不可比， 所以每一行都带难度徽章；每条成绩还会带上随机种子——同一局谁都能照着复现，假数据一眼就露。
