关于我们

中二野人实验室是一个个人独立项目：引擎、文案、界面都是自己写的， 用 Node.js + 原生 HTML/CSS/JS 做成——没有前端框架、没有后端服务、没有账号、没有广告和内购， 也不收集任何数据。当前版本 v2.9.0。

  • 项目性质非商业、个人爱好作品，MIT 许可
  • 运行环境浏览器 / 安卓 5.0+ / Windows 桌面 / Node.js 18+
  • 隐私不收集数据、不联网（除非你自己配了更新地址）、不做统计与广告
  • 内容声明全部为虚构娱乐内容，与任何真实学校、机构、个人无关
